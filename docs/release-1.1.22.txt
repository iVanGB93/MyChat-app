Scope
- Preserves accumulated network routing, wake/recovery and transfer improvements
  in the working tree; this document does not assert new transfer benchmarks.
- Screen capture is bounded at the native source and waits for foreground-service
  acknowledgement. Failed startup rejects capture instead of returning a live
  empty screen track.
- Sender has movable Axonic-style icon-only controls, a small drag handle,
  accessible labels, and an approximately 180 x 80 dp protected overlay.
  Full screen geometry is shared, without bottom cropping. Android obscures the
  overlay with a black rectangle on the receiving side; this is a known accepted
  limitation, not transparent capture of the content underneath it.
- Overlay permission returns are checked before continuing capture. Denial does
  not start sharing; duplicate requests and late results after unmount are gated.
- Stop sharing restores the call presentation; the overlay Stop action requests
  the existing activity. Receiver retains ordinary call controls and a draggable
  self-preview that springs back on release.

  channel with bounded acknowledgement; durable control delivery is retained.
