MARK AS READ KEEPS NOTIFICATION SHADE OPEN — OCTOBER 11, 2026

Cause: the installed Notifee Android 12+ path creates an activity PendingIntent even for action buttons with no launchActivity. Starting that temporary NotificationReceiverActivity collapses Android's notification shade. The Axonic JavaScript action handler already cancels only the current matching message/conversation notification.

Fix: after displaying a decrypted conversation notification, the native NotificationReadAction helper replaces only root-mark-read with an immutable service PendingIntent targeting Notifee's existing ReceiverService ACTION_PRESS_INTENT handler. Action extras identify it as background-only and its semantic action is Mark as read. Other actions, content press, remote input, MessagingStyle and notification metadata are preserved. The replacement update uses onlyAlertOnce to avoid a second sound. Service snapshot autoCancel is disabled so the existing JS handler owns cancellation and protects a newer arrival. Android below API 31 keeps its existing service action path. Helper operates only on this app's own active root-conversation notifications.

Native helper: modules/axonic-nearby/android/src/main/java/expo/modules/axonicnearby/NotificationReadAction.kt. Registered through AxonicNearbyModule and invoked by rootMessageWake. This relies on the installed Notifee core's existing service name, action string and serialized notification bundle; review this integration when upgrading Notifee.

Validation: local assembleDebug with axonicSideBySide=true and arm64-v8a succeeded. APK application ID verified as com.axonic.dev, version 1.1.8, before adb install -r on R3GYC0H7PMY. Dev identity/data preserved; official com.axonic app untouched. Live real emulator-to-Dev group message: tapped Mark as read in the actual notification. Android SystemUI notification stack stayed open, the test conversation card disappeared, six other notification rows remained, and the inbox message's read flag became true. Evidence: builds/mark-read-shade-phone-evidence.json. Shade left open after testing.
32 notification/action tests passed; TypeScript, service cycles and module boundaries passed. Added regression checking that Mark as read preserves other conversation cards. No production build, deployment, commit or push performed. Official/release clients receive this native fix with their next authorized build.

Primary source checked: https://github.com/invertase/notifee/blob/main/android/src/main/java/app/notifee/core/NotificationPendingIntent.java and ReceiverService.java. Installed React Native sources/types also inspected.
