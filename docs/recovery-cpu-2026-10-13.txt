Recovery speed and AoN CPU work - October 13, 2026

Changes
- Mobile outbox continues after a successful direct acknowledgement or custody handoff instead of waiting for another one-second scheduler tick. Existing concurrency limits and failure backoff remain in place.
- AoN chat files reuse immutable validated snapshots while the file stamp is unchanged. Changes, external replacement, and invalid data invalidate or reject the snapshot.
- Read-only hosted chat consumers reuse validated state and dashboard projections. Unchanged capability advertisements do not repeatedly rewrite chat state.
- Indexed custody storage supports immutable read snapshots invalidated by local and external SQLite changes. Monitoring, wake scans, and mailbox polls avoid read-modify-write transactions. Polls retain authorization, exclusions, validation, and expiry filtering; sweeps reclaim expired data.
