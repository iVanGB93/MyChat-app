Pre-build performance review — 2026-11-01

Scope: two existing Android Dev emulators, identities/data preserved. No physical
phone, production build, commit, push, deployment, or official app modification.
Existing unrelated worktree changes preserved.

Changes made during this review:
- RTC data frames no longer wake the idle lease-check pump individually. Native
  credit replenishment and final verification still validate authorization.
- A revoked RTC lease cannot become valid again through a late async check.
- Actual locally admitted RTC/WSS sending streams suppress redundant relay
  materialization/upload. Remote readiness alone cannot suppress custody.
- Stream completion/failure wakes the existing transfer pump. Receipt processing
  remains eligible; no durable hold or additional retry schedule was introduced.
- Recheck stream admission after file preparation and immediately before bulk
  dispatch to avoid a stream starting during preparation racing relay upload.

Follow-up fixes and verification (same day)
-----------------------------------------
Fixed a startup race in rootAttachmentStreams: a first control frame may arrive
before lane.ready's continuation initializes the stream. Hold exactly one bounded
control until start; reject binary/duplicate early frames. Added behavioral tests
with delayed receiver readiness, duplicates and early binary data.

The longer repeats also exposed actual ICE outages. The transport previously
allowed only one restart over the entire connection lifetime. Recovery now rearms
after reconnection, keeping one bounded attempt during an outage. Each new signed
restart binds to the immediately preceding session, so an older offer/answer cannot
authorize a later recovery. Existing identity, device and certificate checks remain.
Tests exercise a second outage, old-parent/old-answer rejection, preservation of
the original data channels and the unchanged disconnect deadline.

Added bounded stream-progress failure diagnostics: protocol state, byte offset,
acknowledged offset, queued bytes and idle duration; no payload or paths.
