Contract: calling.start owns initiation checks, using UI permission callbacks.
Active-call controls and lifetime leases belong to the current session. Do not put
native tracks/streams in persistent UI state. Metadata selectors can be shared;
old-call cleanup must not clear a newer call. Stop sharing is not hang-up.
Screen capture requires OS consent; overlays/native capture are phone adapters.
Group messaging support does not imply an AI supports realtime voice/video.

State authority: coordinator/durable journal for signaling, media session for
tracks and capture, OS for permission. Inspect invitation/acceptance, selected
device, connection route, frame counters and teardown separately.

than treating historical journal rows as work. Bounded passes mark confirmed-empty
call/session pairs idle; journal, connection and policy changes invalidate that
observation. Missing/unverifiable identity and read failures remain retryable.

when no matching direct peer is connected. Call expiry/coordinator clocks remain.
Hosted committed chat writes now wake call-policy handling, matching the phone's
existing policy-event path. These events are hints; send-time checks stay in place.

Remaining scheduling: relay pump fallback/receipt recovery, dashboard lease expiry,
ring/selection deadlines, ICE negotiation and media timeouts are not removed here.
Relay scheduling follow-up: the shared pump now tracks confirmed-empty journal
outboxes per relay session after bounded scans. Historical rows no longer keep
event-capable relays awake. New journal/topology/inbox events clear observations;
unknown records, read errors and unacknowledged events keep retry deadlines.
Peers without event support retain three-second incoming-call fallback polling.
Browser idle call state now refreshes on dashboard SSE. Active calls keep their
one-second lease/media-signaling heartbeat; SSE failure keeps fallback polling.
The SSE connection itself follows panel/page lifecycle events rather than polling
every second. Thirty-second reconciliation remains for status expiry/recovery.
