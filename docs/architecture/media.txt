Contract: reference an existing selected file when possible; source access and
durability must be verified before relying on that reference. Scoped-storage URI
permission, inaccessible sources and picker cancellation are normal outcomes.
Do not promise no temporary copies: preparation/transfer can require temporary
bytes. Avoid an unnecessary permanent Gallery-plus-private duplicate. Cleanup
must distinguish user-owned source, received file, temporary data and relay bytes.
Message descriptor/history can remain even when the user deletes the local file.
Retired formats show an inert resend notice; they must not crash or retransmit.

State authority: durable file/job reference plus OS file availability. A cached
thumbnail/URI is not proof that the full file exists or is safe to send.
