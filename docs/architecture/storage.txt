Contract
  Accept validated transactions/read requests through storage adapters; publish
  revisions after successful commits. Network opens no connections inside these
  persistence operations. Custody services validate protocol admission against
  store capacity/expiry; couriers, not storage adapters, schedule network delivery.
  rootChatLedger belongs to messaging semantics even though it reads/writes here.
  SQLite/file adapters differ across Android/Node. Do not duplicate domain rules.
  A custody commit proves storage, not destination delivery. Delete-for-everyone
  is a messaging action; clearing local history is a different operation.

State authority: durable committed bytes. UI caches and in-flight snapshots cannot
authorize actions, replace recovery evidence, or survive an owner change unchecked.
Keep read failures distinguishable from empty stores; preserve transaction ordering
and account boundaries. Never silently reset a malformed store to make UI fast.

Implemented shared storage boundaries (October 25)
  OwnHistoryStore reads/writes the bound account's serialized history. A null read
  means absent history, not a failed read. Messaging owns ledger interpretation.
  AttachmentJobStore owns resumable jobs and revision compare-and-set operations.
  AttachmentFileStore owns file reads, durable writes and verified publication.
  Relay custody ports hold encrypted packets for recipients; they cannot substitute
  for own jobs/history. Protocol admission remains in custody services.
  The transfer worker receives storage.jobs and storage.files explicitly. Android
  and hosted adapters implement the same contracts without changing stored formats.
