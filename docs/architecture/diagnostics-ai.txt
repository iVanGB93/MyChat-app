Contract: bounded, redacted observations with source revision/runtime fingerprint,
process/network epoch and explicit known/unknown fields. Distinguish created,
queued, stored, delivered, read, webhook accepted and AI processed. Local absence
of a receipt is not confirmed non-delivery. Compare counters only within epochs.

AI clients are adapters to the same account rules, not a parallel message store.
Use stable IDs/cursors, durable pending payloads and verified completion evidence.
Approval must be rechecked at dispatch. Unknown sender approval, destructive
operation approval and OAuth scopes are different gates. Never treat a model's
claim, operational note or HTTP error as verified acceptance.

Integration scope
  SecondNeuron MCP: repository-owned tools/events/auth/idempotency implementation.
  ATOMiX OpenClaw: repository channel plus host config; inspect actual capability
    configuration before claiming Telegram-equivalent tools or group permissions.
  Muse: external VM listener. Local reviewed packages/reports are evidence, not
    a guarantee the VM runs them. Coordinate with Muse; do not maintain an
    untracked second live copy or claim her activation from local tests alone.
