Contracts today
  Public facade starts participation, exposes snapshots/subscriptions and network
  settings. Screens do not send application payloads through it. Composition
  supplies identity records, transports, workers and shared runtime leases.
  Connection selection and persistent sessions are separate from file-transfer
  route selection. Directory identity knowledge is not proof of reachability.
  A connected peer is not proof of delivery; LAN/internet is not a read receipt.
  Every late result must respect owner/session invalidation and shutdown.

State authority: network runtime/pool and verified identity records. UI liveState
is a projection. Native sockets and RTC objects stay in their adapters.
Failures to inspect: discovery vs handshake vs connection loss vs route eligibility.
Record route/peer/attempt correlation without message content or secrets.
