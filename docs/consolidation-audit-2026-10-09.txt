AXONIC CONSOLIDATION AUDIT — OCTOBER 9, 2026

Outcome
The mobile app has one foreground/headless startup: index.ts -> neuron background handlers + LocalAccountApp.
The Django app entry, login/navigation, legacy notification registration, and unused UI/runtime adapters were removed.
No identity, chat, media, or device storage was deleted or migrated.
No production APK was built, no phone was reinstalled, and no commit/push was made for this audit.

Architecture
UI calls module APIs; composition/neuronRuntime owns network lifecycle and foreground/background leases.
The active WebRTC hook has only the neuron adapter; missing/failed transport fails closed.
The localAccountNetwork and rootMediaPicker compatibility forwarding files are removed.
Obsolete production feature flags no longer choose another app.
Axios, Zustand, and qrcode were removed from package dependencies and the lockfile.
check:consolidation now runs with npm run check and rejects unaccounted-for unreachable source.

Validation
590 retained tests; TypeScript; service cycles; module boundaries; consolidation gate.
Android DEVELOPMENT JavaScript bundle exported successfully; this is not an APK or native build.
Shared mobile/AoN protocol source parity checked; this cleanup does not change the deployed AoN protocol.
Legacy-only tests were retired with their implementations; a lower count is not a claim of greater coverage.

Remaining boundaries and limitations
Native dependency/configuration audit found dormant integrations (Google sign-in, Expo background-task/task-manager/notifications/observe, foreground-service, and share-intent). They remain installed/configured until a separately validated native rebuild removes them. Their old JavaScript entry/handlers are gone.
Optional Sentry adapter and privacy filter remain; telemetry has not been newly enabled.
Native-module compatibility and physical-device behavior still need validation with the next approved local build.
Portable hosted compatibility adapters remain intentionally outside the mobile entry graph, listed below. Test-only implementations were moved to tests/support/. This is not a claim that every historical protocol has been removed from the AoNs.
The automated reachability check follows static imports, exports, require and literal dynamic imports; semantic duplication still requires review.
